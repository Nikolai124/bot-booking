# Бот записи к мастеру

Telegram-бот для онлайн-записи в барбершоп, салон или к частному мастеру. Клиент сам выбирает услугу, день и свободное время, а мастер получает уведомление и видит расписание прямо в Telegram.

**Демо:** [@ИМЯ_БОТА](https://t.me/ИМЯ_БОТА)

## Возможности

**Для клиента**
- Запись в несколько нажатий: услуга → день → свободное время → подтверждение
- Бот показывает только реально свободное время с учётом длительности услуги и рабочих часов
- Телефон спрашивается один раз (кнопкой «Отправить мой номер» или вручную), дальше подставляется сам
- «Мои записи»: список будущих записей и отмена в одно нажатие
- Напоминание за сутки до визита

**Для мастера**
- Уведомление о каждой новой записи и отмене
- `/admin`: расписание по дням, отмена записи с автоматическим уведомлением клиента

**Под капотом**
- Защита от двойной записи: время перепроверяется в момент подтверждения
- Нельзя отменить чужую запись, даже подделав данные кнопки
- SQLite для локальной разработки и PostgreSQL на сервере без изменений в коде
- Услуги, цены, рабочие часы и выходные настраиваются в `config.py`

## Стек

Python 3.12, aiogram 3 (FSM, callback data, вебхук на aiohttp), SQLAlchemy 2 (async), SQLite / PostgreSQL.

## Структура

```
bot-booking\
├── bot.py             запуск: polling локально, вебхук на сервере
├── config.py          настройки бизнеса и окружения
├── db.py              модель записи и запросы к базе
├── slots.py           расчёт свободного времени
├── reminders.py       фоновые напоминания
├── keyboards.py       кнопки
└── handlers\
    ├── common.py      /start, цены, контакты
    ├── booking.py     сценарий записи
    ├── manage.py      «Мои записи» и /admin
    └── fallback.py    ответы на всё непонятное
```

## Запуск локально

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# впиши в .env BOT_TOKEN и ADMIN_ID
python bot.py
```

База `bookings.db` создастся сама рядом с ботом.

## Деплой на Render

На бесплатном Render диск стирается при каждом перезапуске, поэтому записи нужно хранить во внешней базе PostgreSQL.

1. Создай бесплатную базу на [neon.tech](https://neon.tech) и скопируй строку подключения (`postgresql://...`).
2. Залей проект на GitHub.
3. На [render.com](https://render.com): **New → Blueprint** и выбери репозиторий.
4. Впиши `BOT_TOKEN`, `ADMIN_ID` и `DATABASE_URL` (строку из Neon).

На бесплатном тарифе сервис засыпает после 15 минут без запросов: первый ответ после сна приходит с задержкой, а напоминания во время сна не отправляются. Чтобы бот не засыпал, можно настроить пинг главной страницы раз в 10 минут, например через [UptimeRobot](https://uptimerobot.com).
